# 💎 Crystal Age — Crystals & Gemstones Website

A beautiful and responsive crystal shopping website built using **HTML, CSS, and JavaScript** as a first-semester web development project.

## 🌟 About the Project

Crystal Age is a crystal and gemstone website designed to showcase different types of crystals, gemstones, jewellery, and natural minerals.

The website features an attractive layout, responsive navigation, crystal categories, product cards, and a modern design that works across desktop, tablet, and mobile devices.

## ✨ Features

* 📱 **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
* 🎨 **Modern UI** — Elegant purple, white, and gold colour theme.
* 🧭 **Navigation Bar** — Easy navigation between website sections.
* 🍔 **Mobile Menu** — Hamburger menu for smaller screens.
* 🔍 **Search Functionality** — Filter products and categories by name.
* 🖼️ **Image Slider** — Animated hero section featuring crystal images.
* 💎 **Crystal Categories** — Explore different crystal and gemstone collections.
* 🛍️ **Product Gallery** — Display products with images, names, and prices.
* ✨ **Hover Effects** — Smooth transitions and interactive styling.
* 📞 **Footer Section** — Useful links and contact information.

## 🚀 How to Run the Project

Follow these steps to run the website on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/crystal-age-website.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the Project Folder

```bash
cd crystal-age-website
```

### 3. Run the Website

Open `index.html` in your web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## 📱 Responsive Design

The website uses CSS media queries and flexible grid layouts to adapt to different screen sizes.

* **Desktop:** Full navigation and multi-column product layouts.
* **Tablet:** Adjusted category and product grids.
* **Mobile:** Hamburger navigation and compact product cards.
